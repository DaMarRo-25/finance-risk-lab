# Finance & Risk Lab — Plataforma v0.6

Prototipo navegable que separa la portada de las herramientas e incorpora el primer diseño funcional del módulo **Capacidad de Pago**.

## Abrir
Abra `index.html` en un navegador.

## Páginas
- `index.html`: portada ligera.
- `calculadora.html`: simulador de préstamo con transferencia de cuota.
- `capacidad-pago.html`: ingresos, gastos familiares, obligaciones, gastos adicionales y Centro de Análisis.
- `tasas.html`: referencias históricas.
- `aprender.html`: biblioteca educativa inicial.
- `metodologia.html`: principios y cálculos.
- `sobre.html`: proyecto y creador.

## Nota
Es un prototipo de interfaz para revisar estructura, contenidos y experiencia antes de migrarlo a React/TypeScript.
