# Decision de segmentacion de tasas

Fecha de decision: 24 de julio de 2026.
Datos historicos consultados: 31 de marzo de 2025.

## Decision

Las referencias no se agregaran en una sola categoria de prestamos personales ni en una sola categoria de hipotecas.

Se publicaran por separado:

- Personal privado.
- Personal publico o gobierno.
- Jubilados / CSS.
- Primera vivienda con interes preferencial.
- Hipoteca regular no preferencial.
- Prestamo de auto.
- Tarjeta de credito.

## Justificacion

Las condiciones y tasas de estos segmentos son distintas. Mezclarlas produciria una referencia sesgada que no representaria adecuadamente el producto seleccionado por el usuario.

## Metodologia

1. Por banco se calcula el promedio entre la tasa minima y maxima disponible.
2. Si el banco publica una sola tasa valida, se utiliza esa tasa como representativa.
3. Los valores cero y las celdas vacias se consideran no disponibles.
4. Se promedian las tasas representativas de los bancos dentro de cada segmento.
5. La referencia es historica y educativa; no constituye una oferta ni recomendacion.
