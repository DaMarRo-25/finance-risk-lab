# Finance & Risk Lab v3.13 — Aprender

## Objetivo
Mantener la estructura y escala visual del Aprender original, incorporando:
- navegación rápida **Explora por tema**;
- secciones principales desplegables;
- conceptos desplegables;
- preguntas/teasers que expliquen por qué abrir un concepto;
- ejemplos opcionales, sin mostrarlos automáticamente.

## Principio visual
No se amplían las tarjetas para compensar el nuevo texto. Se conserva la tipografía y densidad del sistema existente, con títulos de 14–17 px y teasers compactos.

## Seguridad del alcance
Esta versión modifica la presentación de `aprender.html` y sus estilos específicos. No cambia motores financieros ni contratos de transferencia entre herramientas.

## Estructura
- `assets/` — identidad y recursos.
- `data/` — referencias de datos.
- `docs/` — decisiones y auditorías.
- archivos HTML/JS/CSS — aplicación.
