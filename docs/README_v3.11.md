# Finance & Risk Lab v3.11 — Aprender reorganizado

## Objetivo
Reducir la carga visual de Aprender sin eliminar contenido ni cambiar la metodología financiera existente.

## Cambios
- Se añadió una navegación compacta "Explora por tema".
- Cada tema principal es un acordeón cerrado por defecto.
- Los conceptos dentro de cada tema también son desplegables y cerrados por defecto.
- Se eliminó la apertura automática del primer concepto de costos.
- Los enlaces de tema abren el bloque correspondiente y desplazan al usuario hasta él.
- Se conserva el contenido existente y sus enlaces.
- No se modificó metodologia.html en esta etapa.
- No se modificaron los motores financieros ni las conexiones entre herramientas.

## Principio UX
Ver → elegir tema → abrir → profundizar solo si interesa → continuar.

## Prueba recomendada
1. Abrir Aprender directamente: no debe aparecer un bloque de conceptos completamente desplegado.
2. Pulsar "Tarjetas de crédito": debe abrir solo esa sección.
3. Abrir un concepto: debe mostrar únicamente ese contenido.
4. Volver a cerrar el concepto: el resto permanece cerrado.
5. Usar los demás accesos de "Explora por tema" y comprobar que abren la sección correcta.
6. Probar el enlace a Amortización y Capacidad de Pago.
