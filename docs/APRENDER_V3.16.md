# Aprender v3.16

## Propósito
Aprender funciona como la capa educativa de las herramientas. El usuario puede profundizar en lo que acaba de ver, navegar hacia la herramienta correspondiente y volver a experimentar.

## Segmentación
1. Comparador de propuestas — Propuestas bancarias, Costos y cargos, Resultados.
2. Calculadora y amortización — Calculadora y Amortización.
3. Tarjetas de crédito — Conoce tu tarjeta, Pagos y fechas, Costos, Beneficios.
4. Capacidad de pago — Capacidad y Riesgo.
5. Tasas y referencias — Entender tasas.
6. Contexto de Panamá.

## Regla de contenido
No usar "Otros conceptos" como cajón general. Cada concepto debe pertenecer a la herramienta o recorrido al que ayuda a entender.

## Interacción
- Navegación superior "Explora por tema" abre el tema correspondiente.
- Temas principales cerrados inicialmente.
- Subtemas cerrados inicialmente.
- Conceptos cerrados inicialmente.
- Ejemplos y tips cerrados inicialmente.
- Los hashes antiguos de conceptos principales se conservan cuando aplica.

## Alcance
Esta versión modifica únicamente la estructura y experiencia de Aprender. No modifica la lógica financiera ni las conexiones de las demás herramientas.
