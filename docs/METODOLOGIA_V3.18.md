# Metodología v3.18

La página de Metodología mantiene el formato visual existente y organiza la explicación mediante acordeones por herramienta.

## Principios añadidos
- Ejemplos y datos reales se mantienen separados.
- Los datos solo viajan entre módulos mediante una acción explícita.
- Capacidad de Pago puede funcionar de forma independiente o recibir una obligación desde Calculadora o Tarjetas.
- Amortización no recupera simulaciones antiguas automáticamente.
- Tarjetas usa una metodología distinta a préstamos por su naturaleza rotativa.
- El Comparador de Tarjetas solicita datos propios de tarjeta y permite llevar explícitamente una propuesta al módulo de Tarjetas.

La estructura se mantiene retractil para que la persona elija qué herramienta quiere comprender sin convertir la página en un bloque largo de texto abierto.
